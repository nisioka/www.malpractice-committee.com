## 対応済み（2026-11, Search Console の AMP とページのインデックス）

Search Console のエクスポート（2026-11-22）で、AMP は有効 9 / 無効 4（404 が3、「参照している AMP URL は
AMP ではありません」が1）、ページのインデックスは登録済み 206 / 未登録 486 だった。エクスポートには
個別の URL が無いので、どの URL が当たるかはリポジトリの HTML・サイトマップ・canonical から推定した。

- ✅ **AMP を廃止**: 30 記事が `rel="amphtml"` で実体の無い `<slug>/amp/` を指していた（AMP の 404）。
  `hospital-info/` と `kifmec/` は `?amp` を指しており、静的配信ではクエリが無視されて通常のページが
  返る（「AMP ではありません」）。AMP には検索順位上の利点がもう無く、新しい記事では AMP 版を
  作っていなかったので、直さずにやめた。`_automation/retire_amp.py`（冪等）で次のようにした。
  - 全ページ（480 ファイル）から `rel="amphtml"` を外した。
  - AMP 文書 227 件（`<slug>/amp/` 225 件と `Pamp.html` 2 件）を、同じ内容の通常ページへ送る
    転送ページに置き換えた。GitHub Pages では 301 が使えないので、`rel="canonical"` と即時の
    `meta refresh`（Google は恒久的な転送として扱う）に `location.replace` を添えた。
  - `rel="amphtml"` が指していた実体の無い `<slug>/amp/` 30 件にも同じ転送ページを置いた。
    Google はこれらの URL を知っているので、404 のまま残さない。
  - 複数ページに分かれた記事の2ページ目以降の AMP 版（3件）は canonical が1ページ目を指していたが、
    転送先は同じ内容の通常ページ（`twitter-introduce/2/` など）にした。
- ✅ **ページ送りの nofollow**: `page/N` と `category/medical-accident-investigation-system/page/N` の
  29 ページに、テーマが出していた `noindex,nofollow` が残っていた。ページ送りの先にしか載っていない
  古い記事へのリンクを Google がたどらないので、`noindex,follow` にした。noindex はそのまま。
- ✅ **サイトマップの中身**: noindex のページ送り 27 件が載っていた一方で、単独で公開されている
  `movie/`・`twitter-introduce/`・`kifmec/` が載っていなかった。`build_sitemap.py` はページの HTML を
  読み、noindex のものと canonical が自分以外を指すものを落とし、manifest に載らないトップ直下の
  ページも拾うようにした。`<loc>` はページ自身の canonical なので、日本語の slug も canonical と同じ
  パーセントエンコードになる。446 URL → 422 URL。
- 実体の無いサイト内参照は 3,126 件から 2,959 件になった。減った 167 件は、実体の無い AMP 版を指して
  いた `rel="amphtml"` 30 件と、AMP 版の中の関連記事・カテゴリへのリンク 137 件。
- 未登録 486 件の内訳の推定（理由ごとの件数は Search Console、対応する URL はリポジトリからの推定）:

  | 理由 | 件数 | 当たると見られる URL | 対応 |
  |---|---|---|---|
  | 代替ページ（適切な canonical タグあり） | 182 | AMP 版 225 件、`?amp`・`?share=email`・`?replytocom=` 付きの URL（クエリが無視されて同じページが返り、canonical が元を指す） | 問題ではない。AMP 版は転送になったので、今後は「リダイレクトがあります」に移る見込み |

- **ページ送り（`page/N`）を検索結果に出すか**: 今は noindex,follow（2026-11 に nofollow だけ外した）。
  Google のページ送りの指針は、各ページに自分を指す canonical を付けてリンクをたどれるようにすること
  で、noindex は求めていない。ただ中身は記事カードの一覧で、出しても検索流入はあまり見込めない。出すなら `page/N` の noindex を外し、`build_sitemap.py` が自動で拾う。

  対応しない `</p>`（PR #11・#17）、`<figure>` 内の余分な `</p>`（PR #14、当時の page/17）、post-574 の
